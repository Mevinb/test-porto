
# Professional Portfolio Website

Portfolio site for Mevin Benty, built with React, Vite, Motion, and Tailwind CSS.

## Development

Install dependencies:

```bash
npm install
```

Start local development server:

```bash
npm run dev
```

## Production Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The deployable output is generated in the `dist/` folder.

## Deploy

This project is ready to deploy on static hosts such as Vercel, Netlify, Cloudflare Pages, and GitHub Pages using the `dist/` output from `npm run build`.
